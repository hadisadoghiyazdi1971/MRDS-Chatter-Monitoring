# Public Release Checklist

- [ ] Repository name is journal-independent.
- [ ] Repository description is complete.
- [ ] README accurately matches the final manuscript.
- [ ] All scripts use relative paths.
- [ ] Raw/processed data required for reproduction are present or their external archive is linked.
- [ ] `recording_metadata.csv` matches filenames and labels.
- [ ] Experimental images are publication-safe and have meaningful filenames.
- [ ] No manuscript-review correspondence is included.
- [ ] No API keys, passwords, local usernames, absolute paths, or private configuration files are included.
- [ ] No copyrighted third-party files are redistributed without permission.
- [ ] Authors and ORCIDs in `CITATION.cff` are complete.
- [ ] Repository URL is inserted into `CITATION.cff` and `DATA_CODE_AVAILABILITY.md`.
- [ ] Code and data licenses are selected.
- [ ] A clean-clone reproduction test has been performed.
- [ ] GitHub Release `v1.0.0` is created for the submitted version.
- [ ] If using Zenodo, the release DOI is inserted into the repository and manuscript.
- [ ] Public links are tested in an incognito/private browser window.
