# Licensing

Choose and add explicit licenses before making the final scholarly release.

A common research-repository arrangement is:

- **Source code:** a permissive software license such as MIT or BSD-3-Clause.
- **Original research data and original figures:** a data/content license such as CC BY 4.0, if all authors/institutions permit redistribution.

Do not apply an open license to third-party material unless you have the right to do so.

Once the authors agree on licensing, replace this guidance with the actual license files, for example:

```text
LICENSE-CODE
LICENSE-DATA
```

and state clearly in the root `README.md` which files each license covers.
