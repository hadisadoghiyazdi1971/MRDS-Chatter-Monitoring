# Data and Code Availability

## Recommended manuscript wording

The processed experimental data and source code supporting the findings of this study are publicly available in the project repository at **[GITHUB_REPOSITORY_URL]**. The repository includes the 160 MAT recording archives used as direct inputs to the reported experiments, experimental metadata and frozen condition-disjoint splits, the MRDS implementation, evaluation scripts, and saved numerical results supporting the reported analyses. The original raw WAV corpus is not included in the public repository.

## Preferred wording after DOI archiving

The processed experimental data and source code supporting the findings of this study are publicly available at **[GITHUB_REPOSITORY_URL]**. A versioned archival snapshot corresponding to the reported study is available at **[DOI_URL]**. The archive includes the 160 MAT recording files used as direct computational inputs, experimental metadata and frozen condition-disjoint splits, the MRDS implementation, evaluation scripts, and saved numerical results. The original raw WAV corpus is not included.
